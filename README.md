Advanced Database Security System Using Tiled Bitmap Algorithm

An Advanced Database Security System developed in Java to provide secure client and administrator access, database operations, data integrity monitoring, and automated tamper detection using the Tiled Bitmap Algorithm.

The system is designed to identify unauthorized database modifications and improve the integrity and security of stored data.

Key Features

- Secure Admin and Client authentication
- Admin registration and profile management
- Client registration, login, and profile management
- Secure database storage and retrieval
- Client data viewing and downloading
- Database operation monitoring
- Tiled Bitmap based database integrity verification
- Database tamper detection
- Tampered field identification
- Database restoration support
- Automated tamper detection using a background thread
- Email notification for detected security events
- Excel data operations
- Input validation and secure database handling

Objective

The main objective of this project is to build a secure database environment where unauthorized changes can be detected, affected fields can be identified, and the database can be restored when required.

This project combines database management, cybersecurity, algorithm design, and Java application development into a single client-admin security system.
